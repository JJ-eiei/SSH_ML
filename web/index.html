Burst Brute Force (ชัดเจน)

IP เดียวยิง failed password รัวๆ ใส่ account เดียว ไม่มี success เลย — ควรจับได้เกือบ 100%

ดาวน์โหลด
ATTACK

Focused Brute Force

หลาย password ถูกยิงใส่ account เดียว จำนวน fail/จังหวะเวลาจงใจให้ใกล้เคียงกับ user ที่พิมพ์ผิดจริง — โมเดลต้องแยกจากพฤติกรรมรวม ไม่ใช่แค่นับ fail

ดาวน์โหลด
ATTACK

Password Spraying

password ที่ใช้บ่อยไม่กี่ตัว กระจายยิงใส่หลาย username จาก IP เดียวหรือไม่กี่ IP

ดาวน์โหลด
ATTACK · NEW

Credential Stuffing

ใช้คู่ username:password ที่ "รู้อยู่แล้ว" (leaked credentials) — fail ต่อ account น้อยกว่าการเดาสุ่มมาก สำเร็จปนอยู่กลางๆ ไม่ใช่ท้ายสุด

ดาวน์โหลด
ATTACK · NEW

Persistent Multi-day (Stealth)

IP เดิมกลับมาซ้ำๆ ~30 sessions กระจายกว่า 2 สัปดาห์ แต่ละ session สั้น/fail น้อยจนดูไม่น่าสงสัยทีละครั้ง — ต้องอาศัย IP-level feature (จำนวน session สะสม/ช่วงวันที่ยังโผล่มา) ถึงจะเห็นภาพรวม ฟีเจอร์ระดับ session อย่างเดียวจับไม่ได้

ดาวน์โหลด
ATTACK · NEW

Coordinated Botnet Spike

~25 IP ต่างกัน ยิง account เป้าหมายเดียวกันพร้อมกันภายในไม่กี่นาที แต่ละ IP เองดูเหมือน burst เล็กๆ ทั่วไป — ต้องอาศัย cross-IP time-window feature (จำนวน IP อื่นที่ยิง target เดียวกันในกรอบ 15 นาที) ถึงจะเห็นการประสานงาน
